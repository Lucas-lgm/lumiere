# Changelog

## v1.0.0 (2025-03-XX)

### Features
- macOS video player with native HDR/EDR pipeline via CAOpenGLLayer
- Dolby Vision Profile 5 support
- libmpv gpu-next backend for accurate color reproduction
- Library-style media browser with folder view
- Subtitle panel with customization
- AI-powered subtitle generation (Whisper.cpp integration)
- Animated image export (WebP / AVIF)
- Thumbnail generation
- Custom keybinding system

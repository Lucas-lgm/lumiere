# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Lumiere, please report it privately.

**Do not** open a public GitHub issue for security vulnerabilities.

Please send details to the maintainers via email or GitHub's private vulnerability reporting system.

We will acknowledge receipt within 48 hours and provide an estimated timeline for a fix.

## Scope

- The Electron main process and renderer
- Native addon (`native/`) — libmpv bindings
- Dependency chain (npm packages, vendored dylibs)
- Build and release pipeline

Out-of-scope: mpv itself, third-party libraries (report upstream).
